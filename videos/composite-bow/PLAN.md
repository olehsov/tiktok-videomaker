# PLAN — Composite Bow: Short Bow, Long Shot (`composite-bow`)

## 1. Summary
- Concept: a short horse bow outshoots a longbow because it is built layer by layer: wood core, horn belly, sinew back, glue, a sealed skin, reflex and stiff siyahs. A limb cross-section inset (upper right) gains each layer as it is added.
- Duration: en 88.331 s (`timings.en.json → videoDurationSec`, voice 86.831 s, source `elevenlabs`).
- Languages: `en` only. Every rule below is written so `uk` / `ru` can be added with no code changes.

**Global conventions (binding for every scene)**
- The archer is always on the **left** of the bow and arrows fly to the **right**. So the **belly (horn, squeezed) is always on the left side of a limb, and the back (sinew, stretched) is always on the right**. This holds in the scene, in the inset, and in the recap.
- Compression / squeeze uses `--ui-blue`. Tension / stretch uses `--ui-heat`. Load uses `--ui-yellow`. Failure ghosts use desaturation plus a red tint (`ghost()` from the kit, or a `--ui-red` overlay polygon at opacity 0.45–0.55). These four bright colours never appear in the scene with any other meaning.
- Times are always expressions of `ctx.cue(action)`, `ctx.word(beat, text, n)`, `ctx.beat(id).start/end`, `ctx.t0`, `ctx.t1`. The only literal numbers allowed are durations and offsets (e.g. `cue + 0.3`, `duration: 0.5`).
- Screen zones (1080×1920): plates at y ≈ 230; corner meter/gauge at x < 430, y 330–560; **LayerInset** circle at x 610–910, y 320–620 (b03–b11); callout card slot at **(40, 1040)** (s2) or **(24, 1040)** (s3), card bottom ≤ 1210; captions at y 1230–1460; nothing readable below y 1520 or right of x 940.

### 2.1 `build.mjs` extensions (builder implements; list them in `KIT_CHANGES.md`)
These are small, generic and data-driven. Without them the overlays show at the wrong moments (see §6).
1. **Anchor timing.** `anchors[id].at` (absolute seconds) is optional for callouts and labels. If present: `at = r3(Math.min(Math.max(a.at, bs), hide - 0.8))`. If absent, the current behaviour stays.
2. **Label size.** `anchors[labelId].maxWidth` and `.max` are passed to `Label` (see §5).
3. **Scene overlay timing.** `render()` may return `overlays: { [beatId]: { stepAt?: seconds, meter?: [{ t, value? }] } }`.
   - `stepAt` replaces the step-plate time in beats that have both a threat plate and a step plate (still `≥ bs + 0.8`).
   - `meter` replaces that beat's single meter keyframe with the given frames. A missing `value` means the script's `onScreen.meter.value`. Frames from all beats are sorted by `t` before `StakesMeter` is called.
4. **Extras.** `src/scenes.mjs` may also `export const extras = [{ id, from, to, render(ctx) }]`. Each extra becomes a clip `<div id="ex-${id}" class="clip kit-abs" data-start=beat(from).start data-duration=… data-track-index="2" style="z-index:4;left:0;top:0;width:1080px;height:1920px">`. It ends at the start of the beat after `to`, minus 0.1 (or at D). The `ctx` is the same as for scenes and covers beats `from..to`. `render` returns `{ html, tl, css }`. Extras do not take part in the "every beat covered once" check. Element ids come from `ctx.id` with the prefix `ex-${id}`.

## 6. Timing rules
- **Resolution:** `build.mjs` matches each `cues[].word` in that beat's timed words (lower-case, edge punctuation stripped, NFC; Nth `occurrence`). `ctx.cue(action)` = the start of that word in absolute seconds. Scene-internal moments use `ctx.word(beatId, text, n)`. Words used here:
  - b02 `cut`, `snaps`
  - b03 `wood` #2
  - b04 `inside`, `pushes`, `spring`
  - b05 `outside`, `snaps`, `rubber`
  - b06 `hide`, `fish`, `bladders`, `then`
  - b07 `glue`
  - b08 `string`
  - b09 `never`, `these`
  - b10 `no`
  
  `ctx.word` exits the build when a word is missing, and other languages will not contain these English words. So scenes call a local helper `wOpt(beatId, text, n, fallback)` instead. It searches `ctx.beat(beatId).words` with `kit.norm` and returns `fallback` (seconds) when the word is absent. That way adding a language needs no code change. Fallbacks:

  | Beat | Word | Fallback |
  | --- | --- | --- |
  | b02 | cut | `cue("ghost-wood-snap") − 0.8` |
  | b02 | snaps | `cue("ghost-wood-snap") + 1.0` |
  | b03 | wood #2 | `cue("core-appear") − 1.2` |
  | b04 | inside | `B.start + 0.3` |
  | b04 | pushes | `cue("horn-spring-demo") + 1.2` |
  | b04 | spring | `B.end − 0.7` |
  | b05 | outside | `B.start + 0.3` |
  | b05 | snaps | `cue("sinew-band-demo") + 1.2` |
  | b05 | rubber | `B.end − 0.8` |
  | b06 | hide | `cue("glue-pot-bond") + 1.3` |
  | b06 | fish | `cue("glue-pot-bond") + 1.8` |
  | b06 | bladders | `cue("glue-pot-bond") + 2.0` |
  | b06 | then | `cue("seasons-pass") − 0.6` |
  | b07 | glue | `cue("ghost-peel") − 1.9` |
  | b08 | string | `cue("string-bow") + 1.2` |
  | b09 | never | `cue("tips-highlight") + 1.0` |
  | b09 | these | `cue("siyah-whip-demo") − 2.4` |
  | b10 | no | `cue("arrow-flight") − 2.5` |

  In §3, `w(…)` means `wOpt(…)` with these fallbacks.
- **Minimum durations:** entrances ≥ 0.3 s (overlays use the kit 0.18 s pop); exits ≥ 0.2 s; morphs ≥ 0.4 s (release / whip 0.3–0.5 s by design); failure ghosts show the failure 1.0–1.5 s, then rewind in 0.3–0.35 s.
- **Clamping:** every action `dur = min(planned, nextEvent − start − 0.1)`. Here `nextEvent` is the next cue or word-time used for the same object, or `ctx.t1`. If the result is < 0.25 s, skip the motion and `set` the end state at `start`. Nothing in a scene may animate after `ctx.t1 − 0.05`.
- **Short beats in another language:**
  - The seasons cycle uses 2 cycles if `B(b07).start − cue("seasons-pass") ≥ 1.5`, else 1 cycle.
  - The ghost hold is `min(1.3, gapToNextCue − 0.45)` but ≥ 0.8.
  - The arrow flight is `min(1.0, ctx.t1 − cue − 0.1)`.
- **Overlay timing:** callouts and labels use the anchor `at` given in §3, clamped by `build.mjs` to `hide − 0.8`. Overlays hide at `max(beat.end + 0.3, beat.start + 1.0, next.start − 0.1)`. The meter keyframes and the b07 step plate use the `overlays` return (§2.1).
- No `Math.random`, `Date.now`, or `repeat: -1`. Use `immediateRender: false` on every later `fromTo` of the same target.
